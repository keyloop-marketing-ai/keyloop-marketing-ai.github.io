Privacy Policy

Keyloop Marketing AI · Last updated 8 October 2026

Keyloop Marketing AI ("the app") is an internal tool used by Keyloop's marketing team. This policy explains what data the app accesses, how it is used, where it is kept, and how access can be removed.

Google data the app accesses

When a team member signs in with Google, the app requests these permissions:

  • Google Ads (adwords): to read campaign performance and settings, and to make changes the team member asks for, in the dealer accounts that Google login already manages.
  • Google Analytics (analytics.readonly, analytics.edit): to read website traffic and conversion reports, and to change property settings (such as key events) when asked.
  • Google Search Console (webmasters): to read search performance and indexing data, and to manage sitemaps when asked.
  • Google Cloud (cloud-platform): only to read the team's shared settings from Google Secret Manager and to store team notes in a Keyloop Cloud Storage bucket. The Google account's own Cloud permissions limit what it can reach.
  • Your email address (openid, email): to show which Google login is connected.

The app only reaches accounts that the signed-in Google login can already access.

How the data is used

  • To answer a team member's request: reports, analysis and recommendations for the dealers Keyloop manages, and changes the team member asks for.
  • Data is sent to Claude, Anthropic's AI assistant, only to answer that request. Keyloop uses Claude Enterprise, under which Anthropic does not use these conversations to train its models.
  • Google user data is not sold, not used for advertising, and not used to develop, improve or train general AI or machine-learning models.

Where data is kept

  • Sign-in tokens are stored in the operating system's secure credential store (Windows Credential Manager or macOS Keychain) on the team member's computer. They are never written to a file and never shown to the AI assistant.
  • Reports, settings, the change history and the undo record are kept in a folder on the team member's computer.
  • Team notes, report data and the change log are kept in a Keyloop-controlled Google Cloud Storage bucket, so the whole team works from the same information.

Data is kept for as long as the marketing team needs it for its work, and can be deleted at any time by deleting the files or bucket contents.

Sharing

Data is shared only within Keyloop's marketing team and with Anthropic as described above. Reports prepared for a dealer contain only that dealer's own data.

Removing access

Any Google account can remove the app's access at any time at myaccount.google.com/permissions. After that, the app can no longer read or change anything with that login.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
